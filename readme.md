# Listagem de usuarios
Aplicacao React web para listar e pesquisar usuarios, usando o [Parcel](https://parceljs.org/).

## Como iniciar
Depois de clonar o projeto, abra o terminal na pasta e execute:

Faz a instalação das dependências do projeto que estão descritas no arquivo **package.json**
```
npm i
```

Executar o projeto em modo de desenvolvimento:
```
npm start
```

Para gerar a versao de producao:
```
npm run build
```

O resultado do build fica na pasta `dist`.
